# 日记 0.0.2

适用于 Android 12 及以上的 ColorOS 手机，安装文件为 arm64 版本。

安装 APK 后，从“记一篇”开始。文字、照片和录音可自由排序；返回时保存草稿，点击“完成”进入时间线。标题不是必填，同一天可以写多篇，也可以改日期补写。

语音模型默认不安装。需要时进入“设置 → 离线语音转写 → 安装模型”。下载约 60.7 MB，安装后约 103.6 MB。安装完成后可在编辑录音时点“在本机转文字”，断网也可使用；转写结果可以校对。删除或停用模型会保留录音与已有文字。

导入相册照片时只保留引用，原照片删除后可能无法显示。在日记中拍照会保存到系统相册；相册自己的云同步由手机设置决定。

“设置 → 导出加密备份”会收集日记、原始录音及能读取的照片，不包含语音模型。密码至少 8 个字符，没有密码找回服务。导入备份时会跳过相同记录，冲突内容保留两个版本。恢复出的照片保存在日记内。

在时间线点击“选择”可勾选多篇并导出 PDF，也可在单篇日记中导出。PDF 包含文字、照片与转写，不含可播放录音；原声由加密备份保存。

每日写作提醒默认关闭；每月备份提醒默认开启，均需要系统通知权限。提醒时间可能受省电设置影响。

应用只在主动检查更新、检查模型更新或安装模型时联网。没有账号、日记云同步或使用统计。

后续升级请直接安装新版 APK 覆盖更新。卸载应用会删除本机日记，卸载前请先导出备份。

0.0.1 使用分段加密备份，仍可恢复 0.0.0 的备份。请先升级应用再导入新版备份，0.0.0 无法读取新版备份。

0.0.2 修复 ColorOS 拍照保存：在系统相机确认后，等待日记保存完成。若相册空间暂时不可用，照片仍保留在日记内并显示提示。升级后可重新拍照验收。
