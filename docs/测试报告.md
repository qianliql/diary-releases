# 日记 0.0.1 测试报告

测试日期：2026-10-15。此版修复大备份内存风险和手动更新的预览版本识别，使用与 0.0.0 相同的包名、签名及数据库结构。属于预发布测试版本。

## 本版已通过

| 项目 | 结果 |
| --- | --- |
| 构建与发布检查 | debug、androidTest、签名 release、发布 lint 均通过 |
| 单元测试 | **16 项通过**，包括旧版备份恢复、分段加密往返、错误密码、篡改、截断、调换分段、追加数据、合并冲突和模型包校验，以及预览应用版本与模型标签的区分 |
| Android 12 模拟器 | **6 项通过**：原有界面、草稿、回收站、备份恢复合并、缺失原图、PDF 测试，加上大文件加密恢复测试 |
| 大文件加密恢复 | **160 MiB** 内容往返，用时 **13.94 秒**，SHA256 一致。测试环境 Java 堆上限 **192 MiB**；另检查每读取一部分内容时已写出相应密文，禁止缓存整份备份。测试临时文件已删除 |
| 新格式完整性 | 64 KiB 分段 AES-256-GCM，认证头部、段号和长度；认证的空结束段防止按段截断；恢复仍在临时目录中完成全部校验后才导入数据库 |
| 旧格式兼容 | 可读取 0.0.0 的 DIARYBK1；0.0.0 无法读取新版 DIARYBK2 |
| 发布版启动 | 含 x86_64 的同源码、同签名、同压缩优化发布构建在模拟器正常冷启动。对外 APK 为 arm64 |
| 签名与 16 KB 对齐 | 签名验证和原生库 ZIP 页面对齐检查通过；签名证书与 0.0.0 完全相同 |
| 基础包 | 无 .onnx 语音权重，默认不安装模型 |

## 0.0.0 的真机结果

手机在本版修复前已按用户要求结束 USB 测试。**手机里已安装的是 0.0.0，本版 0.0.1 尚未在该手机运行。**

已在 Find X5 Pro（PFEM10，Android 16，用户报告 ColorOS 16.0.3）的独立无联网权限 QA 应用上，通过 5 项界面与数据测试、离线普通话与模型删除保留数据检查、麦克风录音/播放/本地通知测试。600 秒重复普通话样本转写用时 131.54 秒。手机 Wi-Fi 保持原样。

语音引擎和相关功能在 0.0.1 未改动，这些结果可作为已有证据，不能替代本版完整真机复验。
