# 日记 0.0.2 测试报告

测试日期：2026-10-15。本版修复用户反馈的 ColorOS 拍照无法保存问题，以及模型下载取消与重复点击问题。预发布测试版。

## 拍照问题与修复

Find X5 Pro 的系统日志明确记录：ColorOS 相机写入日记创建的待发布 MediaStore 图片时抛出 `Only owner is able to interact with pending/trashed item`。这是拍照后日记与相册均不显示的原因。

改为通过只暴露 camera 子目录的 FileProvider 授权单个临时文件。相机返回成功后，由日记校验图片、写入系统相册并解除待发布状态；取消或空图片不产生空相册图片。打开相机前持久保存草稿，返回时按保存的草稿标识附加照片。解码遵循 EXIF 方向并限制尺寸，供预览与 PDF 共用。相册写入失败时保留应用内原图并提示。

参考：[Android FileProvider](https://developer.android.com/reference/androidx/core/content/FileProvider)、[Android 共享媒体存储](https://developer.android.com/training/data-storage/shared/media)。
