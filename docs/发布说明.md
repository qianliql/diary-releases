# 日记 0.0.1 · 备份与更新修复

- 修复照片较多时，Android 加密组件缓存整份备份导致的内存风险。新备份以 64 KiB 分段进行 AES-256-GCM 认证加密，拒绝截断、调换和追加内容。
- 保留恢复 0.0.0 旧备份的能力；请先升级再导入新版备份，0.0.0 无法读取新版备份。
- 手动检查更新可识别数字标签下的预览应用版本，并跳过语音模型标签和草稿。
- 16 项单元测试和 6 项 Android 12 模拟器测试通过；160 MiB 加密恢复约用 14 秒，内容哈希一致。完整范围及尚待真机复验的项目见 TEST-REPORT.md。

与 0.0.0 使用同一包名和签名，请直接覆盖安装，保留本机日记。手机目前安装的是 0.0.0，拔线后可手动下载本版升级。

基础 APK 约 34.15 MB，默认不含语音模型。模型仍为 Whisper tiny INT8，下载约 60.75 MB、解压约 103.61 MB，不进入完整备份。模型下载位于 GitHub 的 models-v1，以及 Gitee 的 v0.0.0 附件，本版无需更换模型。

GitHub 与 Gitee 提供相同的安装包、完整源码压缩包、说明、测试报告和 SHA256。版本从 0.0.0 开始，此后逐次递增并同步两个平台。
