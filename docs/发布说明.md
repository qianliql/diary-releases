# 日记 0.0.0 · 首个测试版

适用于 Android 12 及以上 ColorOS 手机（arm64）。

支持日记时间线和日历、搜索、心情标签、文字照片录音混排、自动草稿、30 天回收站、密码加密完整备份合并，以及 PDF 导出。

离线语音模型默认不安装。基础 APK 约 34.15 MB；设置中主动安装的 Whisper tiny 模型下载约 60.75 MB，解压约 103.61 MB。安装后在本机进行普通话转写，保留原始录音与可编辑文字。

已在 Find X5 Pro / Android 16 验证无联网权限条件下的本地操作和转写；600 秒普通话重复样本处理用时约 132 秒。测试范围和待验收项目见附件《测试报告》。

每次迭代同步 GitHub `qianliql/diary-releases` 和 Gitee `qianlihuo/diary`，两边使用相同版本、文件及 SHA256。源码压缩包不含签名密钥和本机配置。

后续升级请直接覆盖安装，勿卸载，以保留本机日记。语音模型独立安装且不进入完整备份。
